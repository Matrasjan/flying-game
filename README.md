# Flying Game

A fun interactive animation built with Cocos Creator 3.8.6 where an object flies through waypoints in a smooth arc path, leaves a smoke trail, and displays gradient-colored text.

## Features

- **Dynamic Flight Mechanics** - Object smoothly flies through waypoint sequences using Bézier curves
- **Smoke Effect** - Particle smoke trail follows the object during flight
- **Gradient Text Rendering** - Custom material shader enables multi-color gradient text in labels

## Prerequisites

- **Cocos Creator 3.8.6** 
- **Node.js** (with npm)
- **Git**

## Quick Start

Follow these simple steps to run the game:

### 1. Clone the Repository
```bash
git clone <repository-url>
cd flying-game
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Open in Cocos Creator
- Launch **Cocos Creator 3.8.6**
- In the **CocosGameDashboard**, open the project folder
- Wait for the project to load

### 4. Select and Run the Scene
- In the Scene selector, choose **scene.scene**
- Click the **Run** button

### 5. Configure Display
- A browser window will open
- From the resolution dropdown menu, select **1280×720**
- The game will start automatically
